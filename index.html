DEEP DIVE: 「Bad Epoll」Linux カーネル脆弱性——無権限ユーザーが 99% の確率で root 奪取、Android にも波及

研究者 Jaeyoung Chung 氏が発見した Linux カーネルの新たな use-after-free 脆弱性「Bad Epoll」（CVE-2026-46242）が公開された。epoll はプログラムが多数のファイルやネットワーク接続を同時に監視するための Linux 標準機能で、サーバー・ネットワークサービス・ブラウザの多くが利用している。カーネル内の 2 つの処理が同じ内部オブジェクトの解放処理を同時に行おうとすることで発生する競合状態が根本原因で、一方がメモリを解放している最中に、もう一方がそこに書き込みを続けてしまう。 攻撃者は失敗しても繰り返し試行するだけでよく、カーネルをクラッシュさせることなく、脆弱なマシンに対して約 99% の確率で root 権限の奪取に成功する。epoll は無効化できない Linux の基幹機能であるため、回避策は存在しない。影響範囲は Linux デスクトップ・サーバーに加え、Android デバイスにも及ぶ。興味深いことに、この不具合は 2023 年の epoll コード変更にまで遡る 2 つのバグのうちの 1 つで、もう一方の CVE-2026-43074 は Anthropic の AI モデル Mythos が先に発見しており、今回の Bad Epoll は Mythos が見逃した「もう一つのバグ」だった。上流の修正コミット（a6dc643c6931）は既に公開されており、各ディストリビューションは速やかに取り込むべきとされている。
🧠 AI モデルが同じコード領域から片方のバグだけを見つけて満足してしまった、という事実が示唆的だ。AI 支援の脆弱性診断は強力だが「見つけた1件で終わり」ではなく、同一パターンの周辺コードを人間が疑い続ける姿勢は当面手放せない。epoll という無効化不可能な基幹機能が舞台である以上、パッチ適用の遅れが即座に全社的リスクになる点も見過ごせない。
  • CVE-2026-46242——use-after-free による root 権限奪取、成功率は約 99%
  • 回避策なし（epoll は無効化不可）——Linux デスクトップ・サーバー・Android に影響
  • 姉妹バグ CVE-2026-43074 は Anthropic の Mythos が発見済み、Bad Epoll は見逃されていた側
💡 Linux サーバーや Android 向けビルドを運用しているなら、上流コミット a6dc643c6931 を含むカーネル更新を最優先で適用すべきだ。ディストリのパッチ提供状況を今日中に確認したい。
