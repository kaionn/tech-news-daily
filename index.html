DEEP DIVE: Cursor IDE に CVSS 9.8 のゼロクリック RCE 脆弱性「DuneSlide」——プロンプトインジェクションが OS 実行権限に昇格

CVSSスコア 9.8 の重大脆弱性「DuneSlide」（CVE-2026-50548 / CVE-2026-50549）が、セキュリティ企業 Cato AI Labs の研究者によって Cursor IDE に発見された。この 2 件の脆弱性はいずれも「ゼロクリックプロンプトインジェクション」を起点とし、ユーザーが特定の操作を行わなくてもエージェントが悪意ある指示を実行してしまう。攻撃者は Cursor の操作画面を一切触らず、エージェントが MCP 経由で接続しているサービスや Web 検索で取得したページに悪意ある指示を埋め込むだけでよい。 CVE-2026-50548 では、run_terminal_cmd ツールのオプション working_directory に非デフォルトのパスを渡すと、Cursor が検証なしでそのパスを書き込み許可リストへ追加してしまう問題を悪用する。CVE-2026-50549 はシンボリックリンク解決のフォールバックが問題で、チェック対象のパスが存在しないか読み取り禁止になっていると確認処理が失敗し、プロジェクト外のパスへの書き込みがそのまま通ってしまう。この 2 脆弱性を連鎖させると、サンドボックスを突破して OS 上での任意コード実行が達成される。感染した環境では、開発者がサインイン中のクラウドや SaaS ワークスペースも危険にさらされる。Cursor 3.0（2026 年 4 月 2 日リリース）で修正済みであり、それ以前のすべてのバージョンが影響を受ける。
🧠 AI コーディングエージェントの攻撃面はモデル自体ではなく「エージェントが信頼する入力ソース」にある——このことを DuneSlide は明確に示した。MCP の普及と Web ブラウジング統合により、外部コンテンツがエージェントへの命令に化ける経路は今後ますます増える。IDE の更新で今回の穴は塞がれるが、「エージェントが読む全データを攻撃者がコントロールできる可能性」を前提に設計する思想が次世代ツールには不可欠だ。
  • CVE-2026-50548 & CVE-2026-50549：CVSS 9.8、Cato AI Labs 発見——ゼロクリックで MCP / Web 検索経由のプロンプトインジェクションが OS 上での任意コード実行へ昇格
  • 攻撃にユーザー操作は不要——エージェントが外部から読み込むコンテンツに悪意ある指示を仕込むだけで成立
  • Cursor 3.0（2026 年 4 月 2 日リリース）で修正済み、旧バージョン利用中の場合は即時アップデートが必要
💡 Cursor Agent モードや MCP を有効にしている場合は、バージョンを確認して Cursor 3.0 以降への更新を最優先すること——旧バージョンでは Web 検索結果を読むだけで機器を乗っ取られる可能性がある。
