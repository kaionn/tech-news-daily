DEEP DIVE: AWS が 200 超のサービスを再現する「AWS Emulator」を CC0 で公開

AWS は 11 月 11 日、コーディングエージェントがローカルで AWS 相手のテストを回せるようにする AWS Emulator を公開した。400 超の API モデルから生成した 200 超のサービスのエミュレーションを備え、無料・オフラインで動作し、ライセンスは CC0（パブリックドメイン）である。注目すべきは作り方で、コードの記述とテストはすべてエージェントが担い、実際の AWS との挙動差は複数のエージェントチームが照合して検証している。変更はセキュリティレビュー担当を含むマージゲートを通過しない限り取り込まれない。著者の Swami Sivasubramanian 氏は、エージェントがコードを書く時代にエンジニアの仕事は「全行を書くこと」から「エージェントの周囲にガードレールを設計すること」へ移ると論じる。ガードレールとは仕様、実 AWS に対する忠実度テスト、マージゲートを指す。例として、あるレプリケーションエンジンの再実装は初回に約 4 か月かかったが、仕様とテスト環境が揃った状態ではエージェントが約 2 時間で終えたという。インフラをコーディングのループ内に置けば、エージェントは書いた直後に自分の成果物を検証できる。クラウド課金や認証情報を使わずに IAM や S3 の挙動を繰り返し試せるため、CI のコストと待ち時間にも効く。
🧠 エミュレータの価値は忠実度で決まる。公開された「実 AWS との照合」がどの範囲まで通るかは未検証で、IAM の細かい挙動や結果整合性の再現度が採用の分かれ目になるだろう。一方で CC0 の公開は、LocalStack など既存の選択肢との比較を一気に促す。
  • 400 超の API モデルから 200 超の AWS サービスをローカルで再現。無料かつオフライン動作
  • CC0 で公開。実装・テストはエージェントが担当し、実 AWS との忠実度を別のエージェントチームが照合
  • 全変更がセキュリティレビュー担当を含むマージゲートを通過する運用
💡 エージェントが実 AWS を叩かずに自己検証できるため、課金・認証情報・待ち時間なしでテストを反復できる。

Google、閉じた選択肢の判定に特化した「Gemini Decisions API」を公開

Google は、yes/no、多肢選択、ルーブリック採点といった閉集合の判断に特化した Gemini Decisions API（モデル gemini-decision-1）を発表した。1 回の入力（テキスト・画像・音声・動画・PDF、最大 256K トークン）に対し最大 1,000 問を投げられ、各回答に 0〜1 の信頼度が付く。モデルは回答テキストを生成せず、候補を 1 回の順伝播でスコアリングするため、エンドツーエンドで 150〜250 ms を実現する。入力 100 万トークンあたり 0.10 ドルで、出力トークンの課金はない。Google は共通ベンチマークで Gemini 3.5 Flash-Lite（Interactions API）の約 5 分の 1 のコストと説明している。
  • 1 リクエストで最大 1,000 問、入力は最大 256K トークンのマルチモーダル
  • 生成せず 1 回の順伝播でスコア化し、150〜250 ms。入力 $0.10/100 万トークン、出力課金なし
  • Gemini API / AI Studio で利用可（無料枠あり）。OpenRouter・LangChain・Vercel 連携を順次展開
💡 コンテンツ分類やモデレーションで LLM に生成させて後段で解析している場合、信頼度付きの判定に置き換えれば人手レビューへの振り分けを閾値で制御できる。

C++26 が国別投票で否決、C++ 標準として初

ブログによれば、C++26 は ISO の国別投票で承認に至らなかった。承認には参加 P メンバーの 3 分の 2 以上の賛成と、全投票メンバーの反対 4 分の 1 以下が必要だが、P メンバーは 20 中 12 が賛成（60%）、22 メンバー中 9 が反対（41%）だった。争点は事前条件・事後条件の実行時チェックを標準化する Contracts で、委員会内では支持が強かったものの、Stroustrup 氏らが反対し、複数の国がセーフティと設計への懸念を示した。Profiles は C++26 に入らなかった。次の委員会会合は 11 月 16〜21 日だが、解決には 1 年ほどかかる可能性がある。
  • 賛成 12/20 の P メンバー（60%）で 3 分の 2 に届かず、反対 9/22（41%）で上限 25% を超過
  • 争点は Contracts。Profiles は C++26 に未収録
  • 次回会合は 11 月 16〜21 日、決着まで約 1 年の見込み
💡 C++26 を前提にしたコードベースは、機能の取り込み範囲が変わる可能性がある。コンパイラの実装済み機能を基準に採用を判断したい（記述は筆者の見解を含む）。
