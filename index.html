  • サイバー攻撃依頼への拒否率96.6%、エージェント攻撃耐性(B3 Agent Security Benchmark)97.1%でプレビュー比3.8ポイント向上
  • 価格は入力100万トークン0.70ドル・出力2.10ドルで、Hugging Face・Microsoft Foundry・NVIDIA NIMなど複数経路で提供、商用MaaS提供には別ライセンスが必要

Dev 📜 解説

Rustの`Future`に欠けている「完了後」状態、`Poll::Done`追加案をyoshuawuyts氏が提起

RustのFutureはReady/Pendingの2状態しか返せず、Ready後に再度pollすると未定義動作になる(通常はパニック)。回避策の`MaybeDone`は余分な管理コストを持ち、`FusedFuture`はPendingを転用するため`is_terminated`の確認漏れが呼び出し元のハングを招き得ると、yoshuawuyts氏が指摘した。
  • `Poll`に`Done`列を追加すれば`join`等での完了管理が`MaybeDone`なしに行え、組み込み向けにはunwind対応コードを減らせるが、`Poll`が`#[non_exhaustive]`でないため追加には`poll`自体の非推奨化が必要
  • 未安定の`CoroutineState`には追加しやすいとして`Done`列導入と、`Yielded`/`Complete`を`ControlFlow`命名に合わせ`Yield`/`Return`へ改名する提案も行う
