DEEP DIVE: Bad Epoll（CVE-2026-46242）——Linux カーネル 0-day で無権限ユーザーが 99% の確率で root を取得、サーバー・デスクトップ・Android 全滅

「Bad Epoll」と命名された Linux カーネルの深刻な特権昇格脆弱性（CVE-2026-46242）が 2026 年 7 月に公開された。研究者 Jaeyoung Chung が発見した本脆弱性は、高性能サーバーが広く採用する I/O 多重化機構「epoll」サブシステムに潜む race condition と use-after-free の組み合わせで、特権を持たない一般ユーザーがカーネルメモリを破壊し root 権限を取得できる。影響範囲は Linux カーネル 5.10 から 6.11 と広大で、Linux デスクトップ・クラウドサーバー・Android デバイスすべてに及ぶ。公開された PoC コードによる実証では root 権限取得の成功率が約 99% に達することが確認されており、実用的なエクスプロイトとして実質的に完成している。epoll は nginx・Apache・Node.js・Python asyncio・主要データベースのイベントループが広く採用する仕組みであり、インターネット上の大多数のサービスが何らかの形で影響下に置かれる。特筆すべきは発見の経緯で、本脆弱性の片割れ（CVE-2026-43074）は AI コードレビューツール「Mythos」が 2026 年初頭に先行発見してパッチが当たっていたが、同一の 2023 年コミット由来の第二の欠陥が見落とされていた。epoll を無効化するワークアラウンドは存在しないため、カーネルパッチの適用が唯一の対策となる。各ディストリビューションはすでに修正カーネルを配布しており、PoC コードが GitHub 上で公開済みの今、速やかなアップデートが急務だ。パッチ未適用のシステムは今この瞬間も攻撃リスクにさらされている。
🧠 AI コードレビューが一方の欠陥を発見しながら、同一コミット由来の二つ目を見逃した事実は AI 静的解析の現実的な限界を示す。エクスプロイト成功率 99% と PoC 公開が重なった以上「週次メンテナンスで対応」では遅い。週明け月曜の今日、すべての運用チームがカーネルバージョンを確認し即時パッチ計画を立てるべきだ。特にクラウド上の共有マルチテナント環境では、同じホスト上の別テナントへの横移動に悪用される可能性もある点で影響は単一サーバーの侵害を超えうる。
  • 影響範囲: Linux カーネル v5.10〜v6.11、Linux デスクトップ・サーバー・全 Android デバイス
  • PoC の exploit 成功率 ≈ 99%、PoC コードは GitHub（J-jaeyoung/bad-epoll）に公開済み
  • AI コードレビュー「Mythos」が姉妹脆弱性（CVE-2026-43074）を先行発見するも、同一コミット由来の CVE-2026-46242 は見落とし
💡 epoll を使う nginx・Node.js・Python asyncio など主要ランタイムが対象に入るため、本番 Linux サーバーを持つすべての組織は今日中にカーネル更新計画を確認すること。ワークアラウンドは存在しないのでパッチ一択だ。
