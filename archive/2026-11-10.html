DEEP DIVE: Anthropic が Claude Fable 5.2 と Mythos 5.2 を公開、FrontierSWE v2 で 69.9%

Anthropic は 11 月 9 日、同一の基盤モデルから Fable 5.2 と Mythos 5.2 を公開した。Fable 5.2 はサイバーとバイオの安全策を備えて全ユーザーに開放され、Mythos 5.2 はサイバー・ライフサイエンスの検証プログラムを通過した組織だけが使える。API モデル ID は claude-fable-5-2 で、AWS・Google Cloud・Azure でも同日に利用できる。価格は入力 100 万トークンあたり $8、出力 $40。出力速度を最大 2.5 倍にする Fast mode は $16 / $80 である。性能は Opus 5.5 比で FrontierCode 2.0 が 45.5% から 49.1%、FrontierSWE v2 が 62.3% から 69.9%、AutomationBench が 42.5% から 51.4%、Remote Labor Index が 21.3% から 41.3% と伸びた。効率面では Medium effort のトークン消費が Fable 5.1 より少なく、High effort では Opus 5.5 の FrontierCode 最高スコアにほぼ並びつつ 1 タスクあたりのコストは約半分とされる。大きなモデルが方針を決め小さなモデルへ作業を委ねる Orchestrator 運用と、小さなモデルの相談役となる Advisor 運用の両方に対応する。安全面では、Fable 5.1 と比べ誤ブロックが約 55% 減り、蒸留対策で収集されるデータは 90〜99% 減ったという。Mythos 5.2 は社内の CVE 再発見評価で 89.6% を記録した。
🧠 数字は自社評価が中心で、独立検証は始まったばかりだ。HN では Artificial Analysis が 65 点と過去最高を付けたという投稿が伸びており、第三者の裏付けは出つつある。ただし単価は Opus 5.5 より高い前提なので、「タスクあたり半額」は High effort という条件付きの話にすぎない。未検証だが、Orchestrator 運用で小モデルへ委譲できる比率が実コストを左右するとみている。
  • FrontierSWE v2 は 69.9%（Opus 5.5 は 62.3%）、Remote Labor Index は 41.3%（同 21.3%）
  • 価格は $8 / $40（100 万トークン）。Fast mode は最大 2.5 倍速で $16 / $80
  • Claude Code の既定である Medium effort で、Fable 5.1 よりトークン消費が減る
💡 Claude Code や API で Opus 5.5 を使っているなら、High effort で同等スコアが半額で得られるか自分のタスクで測る価値がある。

Google、Kubernetes で AI エージェントを 10 倍高密度に動かす「Agent Substrate」と gVisor を CNCF に寄贈

AI エージェントは実行時間の 90〜95% を、モデル推論や外部 API の応答、人間の承認の待機に使う。その間も Pod はリソースを握り続ける。Agent Substrate は待機中のエージェント状態をスナップショットとして高速ストレージに退避し、再開時にコールドスタートなしで復元する。Google は従来比 10 倍の密度で動かせるとしている。サンドボックスの gVisor も合わせて CNCF へ寄贈され、GKE では Agent Substrate が正式サービスになった。
  • 待機が実行時間の 90〜95% を占めるため、アイドル中の状態退避で Pod の占有を減らす
  • 密度は従来比 10 倍（Google 発表値）
  • GKE で正式サービス化、gVisor は実行環境の分離を担う
💡 エージェント基盤を自前で Kubernetes 上に組んでいるなら、アイドル時のリソース占有が最大のコスト要因になる。CNCF 標準になるかを注視したい。
