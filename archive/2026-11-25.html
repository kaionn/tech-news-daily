DEEP DIVE: Check Point 管理サーバー 24 台を狙う侵入キャンペーン、GreyNoise が 22 組織の被害を確認

GreyNoise は、GT13 と呼ぶ攻撃者が Check Point Security Management Server 24 台を侵害したとする調査を公開した。発端は 10 月 2 日。攻撃者は未パッチの Rejetto HFS（CVE-2026-61500）でセッションクッキーを偽造して管理者権限を得て、10 月 5 日に SSH 鍵を仕込んだ。10 月 19〜20 日にはこのサーバーを中継点にし、Nmap と Chisel を導入した。そこから SmartConsole の認証バイパス（CVE-2026-16232）で Run Script を悪用し、ファイアウォールのデータベースと内部 CA ファイルを複製した。10 月 26 日には 24 台に対して証明書の一括タスクを走らせ、出力には実装物の可能性を示す痕跡が残った。被害は金融、エネルギー、政府、運輸、鉱業、製造など少なくとも 22 組織。観測した通信は 99 個の IP から 1,400 セッション超、コマンドライン痕跡 800 件超、ファイル 1,200 件超に及ぶ。攻撃者は 11 月 2 日ごろ中継点自身の脆弱性を nftables で塞ぎ、そこで可視性が途切れた。報告は 11 月 23 日公開で、GreyNoise は侵入が現在も続いていると見ている。
🧠 管理サーバーは配下の全ファイアウォールのポリシーと CA を握るため、1 台の侵害が組織全体の信頼基盤に及ぶ。その意味で今回の本質は、境界機器ではなく管理系の足元にある無関係な HFS を足がかりにした点だ。実際、最初の侵入口は Check Point 自身ではなかった。ただし 10/26 の出力に残る implant の疑いは、GreyNoise 自身が確定していない。複製された CA ファイルが実際に悪用されたかは未検証で、被害範囲は今後広がる余地がある。
  • HFS の CVE-2026-61500 でクッキーを偽造し、パスワードなしで管理者権限を取得（10/2）
  • SmartConsole の CVE-2026-16232 で Run Script を実行し、FW データベースと内部 CA ファイルを複製（10/20〜26）
  • 被害は 22 組織・管理サーバー 24 台、攻撃元 IP は 99 個（多くは ExpressVPN 出口か侵害済み端末）
💡 Check Point 管理サーバーを運用している場合、SmartConsole 経路の CVE-2026-16232 を最優先で確認し、authorized_keys と /etc/ld.so.preload の改変、想定外の証明書発行を点検すること。

楽天証券が情報漏えい第 2 報を公表、個人情報は約 441 万件

楽天証券は 11 月 24 日の第 2 報で、漏えいした個人情報が約 441 万件に上ると公表した。内訳は口座保有者が約 322 万件、口座を持たない人が約 119 万件。氏名、生年月日、住所、電話番号に加え、第 1 報（11/17）以降に性別、国籍、FAX 番号、口座の申込・解約状況などが追加で判明した。預かり資産残高の情報は約 168 万件、自己申告の資産情報は約 271 万件に及ぶが、年収と資産は範囲区分のみで正確な金額ではない。顧客コードとログイン ID だけなら約 1,198 万口座分で、集計範囲が異なり重複を含む可能性があるとの注記が付く。ログインパスワードと取引に必要な暗証番号は漏れていない。不正アクセスや不正取引は確認されていない。原因は調査中のままで、同社は構造的な改善策を検討するとしている。
  • 個人情報 約 441 万件（口座保有者 約 322 万 + 非保有者 約 119 万）
  • 預かり資産 約 168 万件、自己申告資産 約 271 万件、年収 約 1.4 万件（いずれも範囲区分）
  • パスワードと暗証番号は対象外、原因は調査中
💡 楽天証券の口座を持つなら、住所・電話番号を使ったフィッシングや SMS 詐欺への警戒が必要。ログイン ID が漏れた範囲では、他サービスで同じ ID を使い回していないかも確認したい。

GPT-6 系モデルがタンパク質設計能力を示す、ラボ実験で 35/322 のミニバインダーが結合

OpenAI は、GPT-6 系モデルが推論とコード実行だけでタンパク質の形状とアミノ酸配列を設計できたと発表した。パートナーの Onava によるラボ試験では、設計した形状から作ったミニバインダー 322 個のうち 35 個（10.9%）が標的に結合した。既知構造への新規配列では MDM2 で 75/88（85%）、VEGF-A で 26/42（62%）、PD-1 で 8/59（14%）。VHH 抗体の IL-4Rα 向けループ再設計は 182 個中 128 個（70%）が結合した。一方、全長のタンパク質構造予測は平均 TM-score 0.38 で、ESMFold2 の 0.93 に遠く及ばない。ProteinMPNN や Boltz-2 などの専用モデルを候補選別に併用しており、完全な end-to-end 設計ではない。
  • モチーフ足場設計（MotifBench 30 課題）の成功率は 43.7%、RFdiffusion の 27.8% を上回る
  • 抗体ドッキングの平均 DockQ は GPT-5.6 の 0.05 から GPT-6.2 で 0.57、社内モデルで 0.81
  • 専用モデルを選別に併用、結合は初期段階の指標で特異性・安定性・安全性は未検証
💡 汎用 LLM が専門モデルに近い領域へ入りつつあるが、結合率は選別工程込みの数字である。創薬領域で使うなら、全長構造予測の弱さを前提に専用ツールと組み合わせる設計が現実的だ。
